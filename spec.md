World end sms network

this project is design for world end sinario that all network is destroyed, but want to make a comunication network for demo propose

Supported Device
- ESP32 (CYD ESP32-2432S028)

UI
- view message (show message routing)
- send message (on screen keyboard)

Network
- ESP32 wifi mesh
- Board cast UDP/TCP
- AES encryption (per sub network aka key)

Message type
- text EN
- emoji
